Shortcuts

Keyboard (FastTracker 2 layout, physical keys): ZSXDC… lower octave, Q2W3E… upper octave · F1–F8 octave · 1 / CapsLock key-off.

Play: Enter song from the start · Shift+Enter song from this pattern · ⌘/Ctrl+Enter loop this pattern · Space stop; when stopped, edit mode on/off (off: the keys only play; red frame = on) · ⌘/Ctrl+F follow on/off · Shift+M mute channel · ⌘/Ctrl+Shift+M invert mutes · Shift+U unmute all · click a channel's header or tile: mute, right-click: solo (again: all back).

Move: ↑↓←→ PgUp/PgDn Home/End · F9–F12 row 0, ¼, ½, ¾ · Tab/Shift+Tab channel · Shift+↑↓ instrument · Shift+←→ order position · Alt+Q…I channel 0–7 · ` / Shift+` edit step up/down · ⌘/Ctrl+←→ pattern number in the order · ⌘/Ctrl+F9/F10 delete/insert order position.

Edit (edit mode on): Del / Backspace clear field · Shift+Del cell · ⌘/Ctrl+Del volume and effect · Alt+Del effect · Ins / Alt+Backspace insert space in the channel · Shift+Ins / Shift+Alt+Backspace insert a row in all channels · Shift+Backspace delete row (pull up) · type hex in the inst/vol/effect columns.

Blocks: Alt+arrow keys (or Shift+PgUp/PgDn/Home/End) or drag with the mouse = select · ⌘/Ctrl+C / X / V or Alt+F4 / F3 / F5 copy / cut / paste (at the cursor; edit mode on or off) · Shift+F3/F4/F5 the channel · ⌘/Ctrl+F3/F4/F5 the pattern · Del delete selection · Esc drop selection · ⌘/Ctrl+Z undo · ⌘/Ctrl+Shift+Z redo · ⌘/Ctrl+S save the song · ⌘/Ctrl+O load a song.

On a Mac the F keys need fn (unless "Use F1, F2… as standard function keys" is on).

Effects: 3xx tone porta · 4xy vibrato · 8xx pan · 9xx sample offset (xx/256 of the region, no pre-roll) · Axy vol slide · E9x retrig (stutter from the hit) · ECx note cut · EDx note delay · Fxx speed/BPM · Video only: Sxx zoom/shake punch · Ixx color-invert flash.

What you see: volume × envelope = brightness · pitch = video speed (C-5 twice as fast, C-3 half-speed slow motion) · vibrato makes the video wobble too.

Adding videos: drop a video on the page → new instrument · drop a .poop → open the song.

Bench (⌘/Ctrl+B, a long video in, pieces out as instruments): Space play/pause · ←→ 1 s · Shift+←→ 10 s · , . a frame · Home/End · timeline zoom: wheel or pinch, = / -, 0 all; sideways scroll or Shift+wheel moves along · I / O piece start / end (or drag on the timeline) · Shift+Space play the piece · Enter cut it → new instrument (not re-encoded; MP4, MOV, WebM, MKV) · Shift+Enter cut it → the selected instrument's video (Repl.: how it sounds is kept) · Esc unmark · click the picture: the focus, the point the instrument's tiles keep in view (the frame shows what a one-channel tile sees) · Backspace focus back to the middle. The bench is never saved: what isn't cut is thrown away.
